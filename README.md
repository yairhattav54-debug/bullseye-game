# 🎯 BULLSEYE – Code Breaking Game

**BULLSEYE** is a fun and challenging color guessing game inspired by the classic **Mastermind** game.

The goal is to **crack the secret combination of 4 colors** within a limited number of attempts.

## 🎮 How to Play

1. The computer randomly generates a **secret combination of 4 colors**.
2. Choose **4 colors** from the available color options.
3. Click **Submit Guess** to check your guess.
4. After each guess, you will receive feedback:
   - 🔴 **Bull:** A correct color in the correct position.
   - ⚪ **Hit:** A correct color in the wrong position.
5. Use the feedback to improve your next guess.
6. Guess the complete combination before running out of attempts to **win the game!**

## ⭐ Game Features

- 🎨 **6 Available Colors:** Choose from six different colors.
- 🎚️ **3 Difficulty Levels:** Choose between Easy, Medium and Hard.
- 🏆 **Scoring System:** Earn points based on your performance.
- 🥇 **Personal Best:** Your highest score is saved automatically.
- 🔄 **New Game:** Start a new challenge whenever you want.

## 🏆 Objective

Crack the secret color combination using **logic, strategy and deduction**.

The fewer attempts you need, the better your result!

**Good luck and have fun! 🎯**
